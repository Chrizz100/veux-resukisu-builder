## About this Kernel

Custom kernel for **Xiaomi/POCO VEUX (SM6375)**.

Built and tested for **HyperOS Android 13 / OS1.0.12.0.TKCMIXM** and based on **Positron Kernel 5.4.803**.
Backportet to 5.4.274.
Veux/Peux kernels will generally be released.

Included:
- ReSukiSU
- SUSFS 2.2
- newer relevant SUSFS fixes for OPEN_REDIRECT, SRCU and stability

My build's intended for veux and the tested firmware listed above.
Other ROMs or Android versions may require a separate kernel build or boot package and are not automatically supported.

The project will continue to receive ReSukiSU, SUSFS and kernel updates when they are compatible with veux and have been tested.
